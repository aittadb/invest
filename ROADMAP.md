# Investor App Roadmap

This file records future product direction, not current capability or release commitment. Stable `ROADMAP-NNN` identifiers must not be renumbered or reused. Accepted implementation work moves into `PLAN.md` first.

- [ ] ROADMAP-001: Public campaign overview with configurable identity, concise opportunity summary, phase display, key risks, aggregate-interest presentation, and public legal/privacy/project links.
- [ ] ROADMAP-002: Configured sign-in, owner setup, session handling, access registration, and signed-in navigation.
- [ ] ROADMAP-003: Registered-only information package with sanitized Markdown sections, immutable versions, change log, and material acknowledgments.
- [ ] ROADMAP-004: Non-binding personal and company investment indications with amount rules, country/phase assignment, withdrawal, reactivation, rejection, and aggregate updates.
- [ ] ROADMAP-005: Founder-candidate application flow separated from investment indications.
- [ ] ROADMAP-006: Owner setup, settings, package editor, moderation, manual-notification tracking, reconciliation, exports, and audit history.
- [ ] ROADMAP-007: Production storage adapter once required authorization, consistency, listing, pagination, quota, and non-disclosure behavior is available.
- [ ] ROADMAP-008: Reference AittaDB campaign fixture using runtime configuration only.
